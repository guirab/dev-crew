# T-7 · Nova feature DevCrew

_Plano gerado pelo dev-crew. Atualizado em 2026-10-07 20:07 (UTC)._

## Resumo

Adicionar pela UI um repositório git local já existente: navegador de pastas alimentado por um GET read-only do gateway (listagem + sonda de uma pasta), terceiro card 'Adicionar repositório' no SourcePicker com formulário (nome, branch base, comandos), e novo Command add_repo tratado pelo orquestrador (valida, opcionalmente faz git init + commit vazio, grava em ~/.dev-crew/repos.toml e adiciona a cfg.repos). Contratos mudam como exceção registrada, com schema e tipos TS regenerados.

## Por que assim

Tudo gira em torno de um único contrato novo (AddRepo + tipos de pastas) e de um único fluxo; o front depende dos tipos gerados do back e o back só faz sentido com a UI. Dividir seria por camada (back → front), sequencial e sem paralelismo, só somando merges.

## Riscos

- Windows: unidades via `os.listdrives()` (Python 3.12+, só Windows) e atributos HIDDEN/SYSTEM via `st_file_attributes`; o container de teste é Linux, então esses ramos precisam ser isolados em funções substituíveis por monkeypatch e não podem quebrar fora do Windows. Unidades de rede/CD lentas ou junctions (ex.: 'Minhas Músicas') devem ser omitidas sem travar.
- `git commit --allow-empty` num repo sem commits leva o que estiver no índice: por isso o init recusa repo com índice não vazio; sem essa guarda o critério 'arquivos continuam sem commit' quebra.
- `git init` dentro de uma subpasta de outro repo criaria um repo aninhado: a sonda 'inside_repo' precisa barrar inclusive com init_git=true.
- Comparação de caminhos 'já cadastrado' precisa ser insensível a caixa e a barras no Windows (normcase + resolve); caminhos de crew.toml com `~` já são expandidos pelo RepoCfg.
- O gateway lê `cfg.repos` do mesmo objeto do orquestrador só no processo único (`crew up`/app); rodando `--only gateway` separado, o selo 'já adicionado' não vê repos adicionados até reiniciar (mesma limitação do create_project).
- Testes como root no container: chmod 000 não torna pasta inacessível; simular inacessível por monkeypatch.
